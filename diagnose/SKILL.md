# Diagnose Skill — 项目体检报告

> 一行命令，1 分钟内知道项目是什么、有没有坑、值不值得投入。

## 功能

当 agent 进入陌生项目时，自动扫描项目结构、依赖、关键文件，生成体检报告。

## 使用方式

```
项目路径 → diagnose.py → 体检报告
```

## 输入参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `path` | 项目路径（必填） | `/home/user/my-project` |
| `--save` | 可选，保存报告到文件 | flag |

## 典型调用场景

**场景 1：agent 进入陌生项目**
```
用户：帮我看看 ~/ws2026/some-project 是什么项目
→ agent 调用 diagnose skill
→ 输出体检报告（类型/评分/风险/缺失文件）
```

**场景 2：clone 新项目后快速了解**
```
用户：刚 clone 了一个项目，扫一下
→ agent 调用 diagnose skill
→ 输出体检报告 + 改进建议
```

**场景 3：agent 需要项目上下文**
```
agent 判断：需要了解当前项目的健康状况
→ 自主调用 diagnose skill
→ 输出评分 + 风险等级 + 建议
```

## 依赖

纯 Python，无外部依赖。支持 Node.js / Python / Go 三种项目类型。

## 评分规则

| 项目 | 扣分 |
|------|------|
| 无法识别类型 | -20 |
| 每缺失一个关键文件 | -5 |
| README.md 缺失 | 额外 -10 |
| LICENSE 缺失 | 额外 -5 |
| 无 lock 文件 | -10 |
| 每个 git URL 依赖 | -5 |

| 风险等级 | 分数范围 |
|----------|---------|
| LOW | ≥ 80 |
| MEDIUM | 60-79 |
| HIGH | < 60 |
